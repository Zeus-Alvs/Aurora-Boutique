E-commerce arquitetado sob um modelo poliglota de banco de dados para suportar ingestão automatizada e gestão de estoque em larga escala.

**Engenharia & Arquitetura:**
- **Arquitetura Poliglota de Dados:** Integração de banco de dados relacional (SQLite) com banco NoSQL orientado a documentos (Firestore) para otimizar diferentes domínios de negócio.
- **Motor de Ingestão:** Desenvolvimento de pipelines estruturados para o consumo, processamento e sincronização de dados via integração com APIs externas.
- **Lógica e Regras de Negócio:** Criação do núcleo sistêmico em Python utilizando Django, contemplando um sistema CRUD rigoroso para controle de estoque, fluxo de vendas e segurança de autenticação.
